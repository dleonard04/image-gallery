Dependencies
============

Runtime
-------
Besides Perl core modules (Getopt::Long, Digest::MD5, Sys::Syslog, File::Copy,
Exporter), the code needs two CPAN modules:

  Image::Magick      - PerlMagick, the Perl interface to ImageMagick
                       (https://imagemagick.org)
  Template           - the Template Toolkit (http://www.template-toolkit.org/)

  Component        Debian / Ubuntu (apt)   RHEL / Amazon Linux (dnf/yum)
  ---------        ---------------------   -----------------------------
  Perl             perl                    perl
  PerlMagick       perlmagick              ImageMagick-perl
  Template Toolkit libtemplate-perl        perl-Template-Toolkit

  Debian / Ubuntu:
    sudo apt install perl perlmagick libtemplate-perl

  RHEL / Amazon Linux:
    sudo dnf install perl ImageMagick-perl perl-Template-Toolkit
  On RHEL, ImageMagick-perl and perl-Template-Toolkit come from EPEL; enable it
  first (e.g. `sudo dnf install epel-release`).

Build
-----
Only needed to build packages, not to run the scripts.

  Debian / Ubuntu package build (`make deb`):
    sudo apt install build-essential debhelper dpkg-dev fakeroot
    (debhelper 13 or newer; Debian 12 "bookworm" and newer, Ubuntu 22.04 and newer)

  RPM build (`make rpm`):
    sudo dnf install make rpm-build

  Optional ant-driven RPM build (`make ant-rpm`):
    Debian/Ubuntu: sudo apt install ant ant-optional rpm
    RHEL/Amazon:   sudo dnf install ant rpm-build
